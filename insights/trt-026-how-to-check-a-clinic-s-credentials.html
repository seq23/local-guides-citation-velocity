Important context

How do I verify a TRT clinic's credentials and licensing

Verify three things independently of the clinic's own website: the prescribing clinician's licence through the state medical board, the dispensing pharmacy through the state board of pharmacy, and any claimed board certification through the certifying board's own directory. A clinic that will not name its prescribing clinician cannot be verified at all, and that refusal is the finding. Do this before you pay, because every one of these checks is free and takes minutes.

Copy-ready script

Ask for the details you need in order to verify

Send this in writing. A clinic that will not answer it in writing has answered it.

  1. Who will be prescribing for me — full name and licence type?
  2. In which state is that clinician licensed?
  3. What board certification does the clinician hold, and with which board?
  4. Which pharmacy dispenses the medication?
  5. Is the medication compounded or commercially manufactured?
  6. Will the clinician who prescribes be the one I actually consult with?
Protocol

How to run the checks

Fifteen minutes, before you pay anything.

  1. Search for the state medical board of the state you live in — use the board's own site, not a directory that aggregates it.
  2. Search the clinician's name in the licence lookup. Confirm the licence is active and note the type.
  3. Read any disciplinary record shown, and compare it with what the clinic disclosed.
  4. For a claimed board certification, look the clinician up in that board's own directory.
  5. Search your state board of pharmacy for the dispensing pharmacy.
  6. Save screenshots of what you verified, with the date.
  7. If any check fails or cannot be completed, ask the clinic directly and treat a non-answer as a negative.
