# ADR 2026-06-19-02 — Velocity-Only Publishing

**Decision:** All guides, state pages, question pages, and disambiguators publish in this Velocity repository. Canonical domains are outbound **Find a Provider** destinations only.

**Consequences:**
- no LKG exports;
- no cross-repository pull requests;
- no canonical candidate packages;
- no canonical backlink requirement;
- one deterministic Velocity build, validation, release, and deployment lifecycle.
