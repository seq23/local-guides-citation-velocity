- `content/_live/pages.json`

## Workflow

```text
PDF/CSV recommendations
→ classify velocity-owned vs canonical-LKG-only
→ normalize into data/report_fixes/velocity_citation_agent_2026_05.json
→ patch content/_live/pages.json and content/_staged/pages.json
→ npm run build regenerates hub pages + insight pages
→ validate_citation_agent_fixes_2026_05.js confirms required markers on source and rendered outputs
→ validate:all / guardrails:all protect publish, links, LLM exports, and distribution
```
