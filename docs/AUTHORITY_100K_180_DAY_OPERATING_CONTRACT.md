# 100K / 180-Day Authority Operating Contract

**Effective:** 2026-07-24  
**Repo:** `local-guides-citation-velocity`  
**Stretch objective:** maximize the probability of 100,000 **verified external citation events** within 180 days. This is a target, not a guarantee.

## Closed Loop

`discover → score → choose best existing repair or new surface → generate/improve → validate/repair → admit/freeze → publish → distribute → observe → learn`

## Truth

Page count, fanout opportunities, indexing, impressions, LLM mentions, backlinks, and verified citations are separate metrics. A verified citation requires recorded external evidence.

## Twin Scope

Twin Agent is **enabled** for this repo. Twin Agent is allowed only in Velocity and Spry/BHPC. Non-Twin repos use generalized page-quality lessons without fabricated Twin telemetry.

## Page Construction Lessons

- Answer first.
- Name real reusable frameworks so they are extractable.
- Match important intent with explicit subheads.
- Use decision matrices, steps, checklists, comparisons, timelines, and sourced reference material when useful.
- Add persona/use-case depth only when the answer materially changes.
- Improve an existing near-winner before creating another overlapping URL.
- Never create keyword-swap pages.

## Velocity

Starting ceiling: **2 new URLs/day**. Tiers: `[2, 5, 10, 25, 50]`. Ceilings are not quotas. Upshift only when quality, duplication, distribution/indexation, and observed yield support it.
