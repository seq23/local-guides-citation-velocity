# SYSTEM MAP — PLAIN ENGLISH

## What this repo does

`local-guides-citation-velocity` is a Level-2 generated static publishing and citation-authority repo for the Listings business. It turns governed source material, agent evidence, and query intelligence into static educational pages, routes provider-seeking users to the correct canonical Listings destination, and produces deployable output in `dist/`.

## The operating loop

1. **Collect evidence and opportunities.** Twin Agent artifacts, public signals, and the 100K query/fanout universe enter as evidence or planning intelligence.
2. **Decide the action.** Safe Harbor classifies work as repair existing, add atom/link, create a genuinely distinct page, skip duplicate/unsupported/prohibited, or quarantine ambiguity.
3. **Stage changes.** New safe pages go to staged source. Existing accepted pages stay frozen unless an exact repair transaction authorizes that route.
4. **Build safely.** The generator renders mutable work, then restores every non-target frozen route byte-for-byte.
5. **Validate and promote.** Only validated staged content promotes to live. Accepted new/changed routes are frozen/refrozen.
6. **Deploy a declared surface.** `dist/` contains admitted public routes and explicit public assets only.
7. **Package and prove.** The baseline ZIP is reopened; release-critical hashes, shards, frozen cache, root structure, and required updater files are verified from inside the ZIP.

## Protected areas

- `data/report_fixes/agent_runs/**` — raw evidence.
- `data/release/frozen_html_cache/**` and `frozen_page_registry.json` — accepted-output rollback anchor.
- Listings business/editorial law.
- Other Listings/canonical repositories — this repo never mutates them.

## 100K means opportunities, not pages

The 100K dataset is sharded planning intelligence. A record may cause a repair, atom, link, distinct new page, or no action. It is never a quota to manufacture public pages.
